## 2. 覚えることは3つだけ

| | やること | 使うもの |
|---|---|---|
| ① | **取ってくる** | `requests.get(...)` |
| ② | **分解する** | `BeautifulSoup(...)` |
| ③ | **探す** | `find(...)` / `find_all(...)` |

どのステップも、やっているのはこの3つの組み合わせです。
取ったあとに **選ぶ・ならべる・数える** のは、ふつうの計算です。

## 3. HTML のしくみ

Webページは、**ぜんぶ文字で書かれた設計図**でできています。その設計図が **HTML**。

```html
<h1>サイバー購買部</h1>
```

| 部分 | 名前 | 意味 |
|---|---|---|
| `<h1>` | 開始タグ | ここから見出しです |
| `サイバー購買部` | 中身 | 実際に画面に出る文字 |
| `</h1>` | 終了タグ | 見出しはここまで |

- `< >` で囲まれたものを **タグ** という
- 閉じるほうには **`/`** が付く
- **タグの中にタグが入る**（＝入れ子）

```html
<div>              ← 外の箱
  <h2>メロンパン</h2>   ← 中身
</div>
```

## 4. きょう出てくるタグ

| タグ | 読み | 何を表すか | どこで使う |
|---|---|---|---|
| `<title>` | タイトル | **ブラウザのタブに出る名前** | ステップ1 |
| `<h1>` | エイチワン | ページで一番大きい見出し | ステップ1 |
| `<h2>` | エイチツー | 2番目の見出し（今回は商品名） | ステップ2 |
| `<p>` | ピー | 段落。ふつうの文章 | ステップ4・5 |
| `<div>` | ディブ | **ただの箱**。まとめるための入れもの | ステップ2 |
| `<span>` | スパン | 文の中の**一部分**を囲む小さい印 | ステップ3 |
| `<a>` | エー | **リンク**。`href` が飛び先 | ステップ4 |
| `<sup>` | サップ | 右上に小さく出る字（脚注の `[1]`） | ステップ5 |

### `<title>` と `<h1>` はちがう

| | 出る場所 | 購買部サイトでは |
|---|---|---|
| `<title>` | ブラウザの**タブ** | サイバー購買部 商品一覧 |
| `<h1>` | ページの**中** | サイバー購買部 |

## 5. class ＝ 名札

`<h2>` はページの中にたくさんあります。そのままでは区別できません。
そこで **名札（class）** を付けておきます。

```html
<h2 class="item-name">メロンパン</h2>
```

これで「**`item-name` という名札の付いた `h2` を全部持ってきて**」と頼めます。

`id` も名札ですが、**ページに1つだけ**のときに使います（ステップ5で登場）。

## 6. 商品1つ分の中身（今日の地図）

```html
<div class="item">
  <p  class="item-icon">🍈</p>
  <h2 class="item-name">メロンパン</h2>
  <p  class="item-category">パン</p>
  <p  class="item-price-line"><span class="item-price">150</span>円</p>
  <a  class="item-link" href="items/item01.html">くわしく見る</a>
</div>
```

**このかたまりが30個くり返されています。**

| 名札（class） | 中身 | あるページ |
|---|---|---|
| `item` | 商品1つ分の箱 | 一覧・詳細 |
| `item-name` | 商品名 | 一覧・詳細 |
| `item-price` | **値段の数字だけ**（「円」は外） | 一覧・詳細 |
| `item-category` | カテゴリ | 一覧・詳細 |
| `item-link` | 詳細ページへのリンク | 一覧だけ |
| `item-stock` | 在庫（あり／残りわずか／品切れ） | **詳細だけ** |

> **なぜ「150」と「円」が分けてある？**
> `item-price` の中を数字だけにしておくと、そのまま数として計算に使えるからです。
> 「150円」だと、まず「円」を取りのぞく作業が必要になります。

## 7. Python の命令 早見表

| 書き方 | 意味 |
|---|---|
| `requests.get(URL)` | そのアドレスのページを取ってくる |
| `BeautifulSoup(html, "html.parser")` | 取ってきたページを分解する |
| `soup.title` | `<title>` タグを探す（**タグごと**） |
| `soup.title.text` | その**中身の文字だけ**を取り出す |
| `find("h2", class_="item-name")` | 条件に合う**最初の1つ**を探す |
| `find_all("div", class_="item")` | 条件に合う**全部**を探す |
| `len(items)` | 個数を数える |
| `items[0]` | 1つめ（数え始めは **0**） |
| `items[:5]` | 最初の5つだけ |
| `items[1:]` | 1つめを飛ばして残り全部 |
| `.get("href")` | 属性（`href` など）の中身を取り出す |
| `int("150")` | **文字の150** を **数の150** に変える |
| `for item in items:` | `items` **ぜんぶに対して**1つずつ。取り出した1個が `item` |
| `if price <= 120:` | **もし〜なら**（条件に合うときだけ実行） |
| `prices.append(x)` | リストの**後ろに足す** |
| `prices.sort()` | **小さい順**にならべかえる（`reverse=True` で大きい順） |
| `totals = {}` | **辞書**。名前で覚えておく入れもの |
| `totals.get(cat, 0)` | まだ無ければ **0** として取り出す |
| `round(118.33)` | 四捨五入する |
| `time.sleep(1)` | 1秒待つ |

### 気をつけるところ

- `class_` の**うしろのアンダースコア `_` を忘れない**
  （Python では `class` が別の意味で使われているため）
- `for` の下の行は **半角スペース4つ**で字下げする
- 文字と数はちがう。`"150" + 10` は**エラー**。`int("150") + 10` なら `160`
  （`"150" * 2` はエラーにならないが `150150`。2倍ではなく2回くり返る）
- くらべる記号 … `<` 未満／`<=` 以下／`>` 超／`>=` 以上／`==` 等しい

## 8. エラーが出たら

**エラーは失敗ではありません。** コンピュータからの「ここが分からない」というメッセージです。

| 画面に出る文字 | 何が起きている | どうする |
|---|---|---|
| `NameError: name 'requests' is not defined` | 準備のセルを実行していない | いちばん上のセルから順に実行しなおす |
| `NameError: name 'soup' is not defined` | 途中のセルを飛ばした | 飛ばしたセルを実行する |
| `IndentationError` | **全角スペースが混ざっている**／字下げのずれ | その行を消して、**半角**で打ち直す |
| `AttributeError: 'NoneType' object has no attribute 'text'` | 名札のつづり間違い（見つからなかった） | `class_="..."` の中を1文字ずつ確認する |
| `TypeError: can only concatenate str...` | 文字のまま計算しようとした | `int(...)` で数に変える |
| 日本語が `ã¡ã­ã³` のように化ける | `res.encoding = "utf-8"` の行が消えている | その行を書き戻す |
| `find_all` したのに1つしか出ない | `find` と `find_all` の取りちがえ | `print(len(items))` で個数を確認する |
| 休憩のあと、急に `NameError` だらけ | つながりが切れて、変数が消えた | いちばん上の「準備」から実行しなおす |

> `None` は「**見つからなかった**」という意味です。
> `NoneType` のエラーが出たら、まず名札のつづりを疑ってください。

## 9. 使い方の話

同じコードが、**便利な道具にも、迷惑にもなります。**

- 1回のアクセスは、たいしたことない
- でも、待たずに30回・300回・3000回だったら？
- しかも、この教室には20人いる

**攻撃するつもりがなくても、結果として攻撃になる**ことがあります。
だから今日は、練習用に用意したサイトを使いました。

### 判断するための3つの目安

| 見るもの | 何が分かるか |
|---|---|
| **利用規約** | 「自動で集めてはいけない」と書いてあることがある |
| **robots.txt** | 機械向けの「入っていい／だめ」の案内板。`https://例.com/robots.txt` |
| **間隔** | 1回ごとに1秒あける。急ぐ理由はたいていない |

相手が**データを渡す入口（API）**を用意していることもあります。
そういうときは、そっちを使うほうが速いし、相手にもやさしい。
