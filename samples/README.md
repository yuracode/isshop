# samples/

授業のステップ7で使う、**Wikipedia 記事のスナップショット**を置く場所。

## なぜ保存版なのか

授業中に生徒20人が本物の Wikipedia へ一斉にアクセスするのを避けるため。
講師が事前に1回だけ取得したものを、GitHub Pages 経由で全員が読む。

Wikipedia は「スクレイピング禁止」ではない（robots.txt は記事ページへの低速アクセスを
明示的に歓迎している）。それでも保存版にしているのは、次の理由による。

- 学校の共有グローバルIPから20人が同時に出ると、1つのボットの並列アクセスに見える
- Wikimedia は自動アクセスに連絡先入りの User-Agent を求めており、
  `requests` の既定値（`python-requests/2.x`）では **403 が返る**（2026-09-06 確認）
- 記事はいつでも編集される。前日に通ったコードが当日壊れる
- マナーの話をした直後に全員で外部へ出るのは、伝えたいことと逆になる

本物の記事をブラウザで開くのは自由。人が読むぶんには普通の閲覧で、何の問題もない。

## 収録物

| ファイル | 出典 | 版 | 取得日 |
|---|---|---|---|
| `wikipedia-melonpan.html` | [メロンパン - Wikipedia](https://ja.wikipedia.org/wiki/メロンパン) | oldid=110718365 | 2026-09-06 |

Wikipedia の本文は **CC BY-SA 4.0**（https://creativecommons.org/licenses/by-sa/4.0/ ）。
出典・版・ライセンス・改変点はファイル冒頭の HTML コメントにも書いてある。

**改変点**：`<script>` `<style>` `<link>` を削除し、`<img>` の `src` / `srcset` を外した。
授業中に外部へリクエストが飛ばないようにするためで、本文と HTML の構造は取得時のまま。
ブラウザで開くと装飾は当たらないが、ステップ7で使うのは構造だけなので支障はない。

## 取り直すとき

記事が古くなった、別の記事に差し替えたい、というときは以下。
**取得は1回だけ**。ループで回さないこと。

```bash
UA='CyberKoubaibu-LessonSnapshot/1.0 (https://github.com/yuracode/isshop) curl'
curl -sS -A "$UA" -o /tmp/raw.html "https://ja.wikipedia.org/wiki/メロンパン"
```

取得後、`<script>` `<style>` `<link>` の除去と `<img src>` の除去、
冒頭コメント（出典・版・取得日・ライセンス・改変点）の付与を行う。

記事を差し替えた場合、ノートブックのステップ7で前提にしている次の3点を確認すること。

- `<h1 id="firstHeading">` に記事名が入っている（Wikipedia 共通）
- `find_all("h2")` の**1つ目が「目次」**になる（「いらないものが混ざる」の実演に使う）
- 文書内で最初の `<p>` が記事の書き出しで、`<sup>` の脚注 `[1]` を含む
