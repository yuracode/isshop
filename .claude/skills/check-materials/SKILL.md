# 教材を直したあとの確認

**教材を1つでも直したら、これを通してから終わりにする。**

## 1. 整合性チェック（常に実行）

```bash
python3 tools/check-materials.py
```

31項目を確認する。外部ツールは不要で数秒で終わる。**NG が1件でもあれば直す。**
落ちた項目には直す場所が併記される。よく落ちるものと対処は次のとおり。

| 落ちる項目 | たいていの原因 | 直し方 |
|---|---|---|
| HTML が tools/build-site.py の出力と一致 | `index.html` や `items/*.html` を手で直した | `tools/build-site.py` の `DATA` を直して再生成する。HTML は生成物 |
| 商品数の記述が 30 に揃っている | 商品数を変えたのに文章が古い | 指摘されたファイルの「8つ」「8個」などを直す |
| slides.pptx の枚数が slides.md と一致 | 原稿だけ直して pptx を作りなおしていない | `node tools/slides-to-pptx.mjs` |
| 台本が参照するスライド番号が実在する | スライドを増減したのに `lesson-plan.md` が古い | 台本の「スライドN〜M」を直す |
| タイムテーブルの時刻が積み上がっている | 所要分を変えて開始時刻を直し忘れた | `lesson-plan.md` の表を計算しなおす |
| student.ipynb から外部サイトへのアクセスが無い | 受講生用に外部URLを書いた | **絶対制約違反。** `add-snapshot` スキルを使う |
| 最安値が1商品に定まる | 同額の商品を足した | `DATA` の価格をずらす。答えがぶれると授業が止まる |

## 2. スライドの描画確認（スライドを直したときだけ）

```bash
bash tools/render-slides.sh
```

PDF と PNG にして、**枠からはみ出して消えた文字**を機械的に見つける。
過去に「pptx の中には文字があるのに描画されると消える」事故が起きているので、
**スライドを直したら文字数に関わらず必ず通す。**

はみ出しが出たら、該当スライドを短くするか2枚に分ける。

出力された `slide-NN.png` は目でも見る。見るのは詰まりすぎ・空きすぎの2点。
Linux には Meiryo / MS Gothic が無いので**字幅と絵文字は本番と違う**。位置関係だけ見る。
